// dónde viven las tools

Las tools son
texto en el context.

El model no "tiene" tools. Le llega una lista escrita - nombre, para qué sirve, qué parámetros lleva - y él contesta con un mensaje que dice quiero usar esta, con estos argumentos.

  1. Esa lista va en cada llamada, gastando espacio siempre.
  2. Más tools conectadas = menos sitio para tu código.
  3. El resultado de cada tool también se queda: leer un archivo de 800 líneas lo mete entero en la conversación, y ahí se queda.

Por eso una sesión larga se pone lenta y tonta: no es que se canse, es que ya casi no le cabe nada nuevo.

Tres cosas que
ahora tienen sentido.

  1. La sesión limpia funciona porque bota el ruido, no porque el agent "descanse".
  2. El resumen te miente un poco. Lo que se resumió se comprimió, y lo comprimido pierde detalle sin avisar.
  3. Lo que pusiste temprano pesa menos con el tiempo. Si algo importa, vuélveselo a decir - o ponlo en el AGENTS.md, que entra completo cada vez.
// la idea de la noche

Se ve terminado.
No es lo mismo
que estar terminado.

Un humano junior escribe código que se ve inseguro cuando lo está. El agent escribe código que se ve seguro siempre: nombres correctos, formato limpio, comentarios en su sitio, tests que pasan.

Todas las señales que usabas para calibrar confianza dejaron de funcionar. Hay que revisar distinto.

// cómo se empuja de vuelta

Cuatro movidas,
de suave a fuerte.

1 · Pídele la fuente

"¿De dónde sacaste esto? Cita archivo y línea." La mitad de las invenciones se caen aquí solas.

2 · Pídele que lo rompa

"Escribe un test que falle con este código." Si no puede, o el código está bien o el test no sirve. Las dos respuestas te dicen algo.

3 · Recorta el alcance

"Deshaz todo menos X." Contra el que cambió de más. Más rápido que discutir.

4 · Sesión limpia y pídelo distinto

Si ya se enredó, no lo convenzas. Empieza de cero con mejor prompt. Ayer aprendiste por qué.

// la frase que no funciona

"Está mal,
arréglalo."

Te devuelve otra cosa igual de segura y distinta, y ahora tienes dos versiones que no entiendes. Sin decirle qué está mal, adivina - y adivina rápido.

Revisar es señalar qué y dónde. Eso es todo el trabajo.

// la vara de esta noche

¿Lo firmarías
con tu nombre?

No "¿está bien?". No "¿corre?". ¿Lo mandas a review de tu equipo con tu nombre encima?

Si la respuesta es no, todavía no terminaste - y ya sabes cuál de las cuatro preguntas falló.
