Un agent no predice.
Corre un loop.

01 · gather

Junta contexto

Lee archivos, busca, corre comandos para entender dónde está parado.

Actúa

Escribe, edita, ejecuta. Aquí te pide permiso.

Verifica

Corre lo que escribió y revisa si sirvió. El paso que todos se saltan.

Autocomplete predice la línea que sigue; esto corre el loop hasta terminar. El martes vimos el loop: gather, act, verify. Cuando algo sale mal, casi siempre es el gather - y el gather es context.

// dónde viven las tools

Las tools son
texto en el context.

El model no "tiene" tools. Le llega una lista escrita - nombre, para qué sirve, qué parámetros lleva - y él contesta con un mensaje que dice quiero usar esta, con estos argumentos.

  1. Esa lista va en cada llamada, gastando espacio siempre.
  2. Más tools conectadas = menos sitio para tu código.
  3. El resultado de cada tool también se queda: leer un archivo de 800 líneas lo mete entero en la conversación, y ahí se queda.

Por eso una sesión larga se pone lenta y tonta: no es que se canse, es que ya casi no le cabe nada nuevo.

// y cuando se llena, no te avisa

El context
tiene fondo.

Cada archivo que lee ocupa espacio. Cuando se acaba, lo viejo se cae - y el agent sigue contestando igual de seguro, sin decirte que se le olvidó.

  1. Se le olvidó algo que le dijiste hace rato.
  2. Se repite, o se contradice.
  3. Vuelve a leer archivos que ya había leído.

Eso es la pared. La cura no es un prompt mejor.

// la unidad de trabajo

Una session es
todo lo que recuerda.

abrir

Empieza en cero

No sabe nada de la conversación anterior: las sesiones no se heredan. Solo ve lo que le des y lo que lea.

durante

Todo se queda

Lo que leyó, lo que escribiste, y también los errores y los caminos falsos.

cerrar

Se borra

Suena a pérdida. Es tu mejor herramienta: los errores se borran también.

Por eso el P3 va en sesión limpia. Es la única forma de probar el archivo y no la conversación.

Tres cosas que
ahora tienen sentido.

  1. La sesión limpia funciona porque bota el ruido, no porque el agent "descanse".
  2. El resumen te miente un poco. Lo que se resumió se comprimió, y lo comprimido pierde detalle sin avisar.
  3. Lo que pusiste temprano pesa menos con el tiempo. Si algo importa, vuélveselo a decir - o ponlo en el AGENTS.md, que entra completo cada vez.

// por qué no leyó lo que creías

La búsqueda falla
de cuatro maneras.

  1. Nombre equivocado. Tú piensas "autenticación"; el archivo es guard.js.
  2. Duplicado muerto. Abrió la implementación vieja, que tiene el nombre más obvio.
  3. Convención no escrita. Ve el código; no ve que aquí eso no se hace así.
  4. Se conformó. Tres archivos le alcanzaron para sonar bien, y paró.

Ninguna se ve en la respuesta. Salen todas igual de seguras.
